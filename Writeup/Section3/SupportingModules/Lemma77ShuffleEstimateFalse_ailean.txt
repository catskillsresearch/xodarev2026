**Lemma 77** (paper, Appendix): *assume H2; there is `C` with `‖a ⧢ b‖_w ≤ C ‖a‖_w ‖b‖_w` on `T_w`.* This is false for **every** weight (Definition 9: `w(0) = 1`, `w` increasing), so in particular for every H2 weight. For a single letter `ℓ`, `ℓ^{k} ⧢ ℓ = (k + 1) ℓ^{k+1}`, so `‖ℓ^k ⧢ ℓ‖_w = (k + 1) w(k + 1) ≥ (k + 1) w(k)`, while `‖ℓ^k‖_w ‖ℓ‖_w = w(k) w(1)` (`not_lemma77_shuffle_estimate`). The paper's proof claims the binomial factor `≤ 2ⁿ` is absorbed by "an equivalent weight"; that requires `2ⁿ w(n)`, which is not equivalent to `w`.
