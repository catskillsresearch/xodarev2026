**Theorem** (`theorem_D`). **Theorem D (GKW hedging-error decomposition)**. Fix a complete real inner product space `H_S`, depth `d`, weight `w`, price-filtration signature space `PFS`, and a `GKWDecompositionSetup gkw`. Then three conclusions hold in parallel:

1. **Unique orthogonal GKW decomposition and Pythagorean variance.** For every `X : H_S` there exists a residual `ε_T` such that `X` equals the sum of `gkw.expectationPart X`, `gkw.stochasticIntegralPart X`, and `ε_T`; the residual is orthogonal to every element of `gkw.replicableSubspace`; and `‖X‖² = ‖gkw.expectationPart X + gkw.stochasticIntegralPart X‖² + ‖ε_T‖²`.

2. **Quantitative weight-ratio tail bound on signature payoffs.** For any weight `w'`, series `b` with `MemTw w' b`, truncation level `N`, ratio constant `ρ_N ≥ 0`, and hypothesis that `w n / w' n ≤ ρ_N` for all `n > N`, there exists `Z` in `gkw.replicableSubspace ⊔ PFS.V_subspace N` with `‖gkw.evalSig b - Z‖ ≤ gkw.C_sig * ρ_N * normW w' b`.

3. **Vanishing residual at completeness depth.** If `PFS.V_infty = ⊤` and `N` is at least the completeness depth `PFS.completenessDepth`, then every `X : H_S` lies in `gkw.replicableSubspace ⊔ PFS.V_subspace N`.

Proof. The proof is a triple conjunction; each conjunct is argued separately.

**Part (1): Hilbert projection onto the closed replicable subspace.** Instantiate orthogonal projection from `gkw.replicable_hasOrthProj`. Define `P_X := replicableStarProjection gkw.replicableSubspace X` and `ε_T := X - P_X`. By `gkw.orthProj_split`, `P_X` equals `gkw.expectationPart X + gkw.stochasticIntegralPart X`, which rewrites the decomposition identity once `ε_T` is unfolded. Standard Mathlib theory yields `X - P_X ∈ replicableSubspaceᗮ`, so for each `Z ∈ gkw.replicableSubspace`, inner products `⟪ε_T, Z⟫` vanish via `Submodule.mem_orthogonal'`. Moreover `P_X ∈ gkw.replicableSubspace` as the image of star projection. Write `X = P_X + ε_T`; orthogonality of `P_X` and `ε_T` follows from `horth` applied to `P_X` with membership `hP_mem`, after using `real_inner_comm` to swap factors. Insert this inner-product zero into `norm_add_sq_real` for the pair `(P_X, ε_T)` and use `linarith` to obtain the Pythagorean law `‖X‖² = ‖P_X‖² + ‖ε_T‖²`, which is the variance formula after replacing `P_X` by the GKW split.

**Part (2): Truncate the signature payoff; control the tail by the weight ratio.** Take `Z := gkw.evalSig (projLe N b)`. Membership of `Z` in the desired sup comes from `gkw.evalSig_le_in_V N b` via `Submodule.mem_sup_right`, placing `Z` in `PFS.V_subspace N` and hence in the join with `gkw.replicableSubspace`. Decompose `b` as `projLe N b + projGt N b` using `projGt.add_projLe`, apply additivity `gkw.evalSig_add`, and subtract `Z` to see `gkw.evalSig b - Z = gkw.evalSig (projGt N b)`. The tail payoff therefore has norm bounded by `gkw.evalSig_l2_bound` applied to `projGt N b`, once `tail_norm2wInv_le_ratio_mul_normW` supplies `MemL2wInv` for the tail and the inequality `norm2wInv w (projGt N b) ≤ ρ_N * normW w' b` under the weight-ratio hypothesis. Nonnegativity `gkw.hC_sig_nonneg` lets `mul_le_mul_of_nonneg_left` absorb the tail norm estimate into `gkw.C_sig * ρ_N * normW w' b`, and a short ring calculation reorders the factors.

**Part (3): Depth duality — at or above completeness depth, static span is top and every claim is replicable.** Assume `PFS.V_infty = ⊤` and `PFS.completenessDepth ≤ (N : ℕ∞)`. Define `S_good` as the set of extended naturals `K` for which some finite level `n` has `K = (n : ℕ∞)` and the topological closure of `PFS.V_subspace n` equals `PFS.V_infty`. This set is nonempty: if it were empty, `sInf S_good` would be `⊤` by definition of infimum on an empty set, but `hdepth` forces `sInf S_good ≤ N`, contradicting `not_top_le_coe`. Choose `n₀` with closure `PFS.V_subspace n₀` equal to `V_infty` from `csInf_mem`. Completeness depth bounds give `(n₀ : ℕ∞) ≤ N`, hence `n₀ ≤ N` as naturals. Monotonicity of `V_subspace` lifts the topological-closure inclusion from level `n₀` to level `N`, and comparing with `hVtop` yields `PFS.V_subspace N = ⊤`. Any `X` then satisfies `X ∈ Submodule.top` and thus lies in the right-hand factor of `gkw.replicableSubspace ⊔ PFS.V_subspace N` by `Submodule.mem_sup_right`.
