**Theorem** (`banach_algebra_concat_bound`). Let `w : Weight` satisfy the quasi-submultiplicativity bound `w (m + n) ≤ C_w * w m * w n` for all `m, n : ℕ` with constant `C_w ≥ 1`. For any `a, b : ExtTensorAlgebra d` in `MemTw w`, the concatenation product `a ⊗ₜ b` also lies in `MemTw w` and satisfies `normW w (a ⊗ₜ b) ≤ C_w * normW w a * normW w b`.

Proof. Note `C_w ≥ 0` from `1 ≤ C_w`, and each level term `w n * (a ⊗ₜ b).levelNorm n` is nonnegative. Fix a truncation `N : ℕ` and bound the partial sum `∑ n ∈ Finset.range N, w n * (a ⊗ₜ b).levelNorm n`. First apply the triangle/Cauchy level bound `(a ⊗ₜ b).levelNorm n ≤ ∑ k ∈ Finset.range (n + 1), a.levelNorm k * b.levelNorm (n - k)` (`ExtTensorAlgebra.levelNorm.concat_le`), multiplied by the positive weight `w n`. Distributing `w n` into the inner sum, each index `k ≤ n` satisfies `w n = w (k + (n - k)) ≤ C_w * w k * w (n - k)`, so each summand is bounded by `C_w * (w k * a.levelNorm k) * (w (n - k) * b.levelNorm (n - k))`. Factoring out `C_w ≥ 0` leaves the truncated discrete convolution sum over `n < N` and `k ≤ n`, which is bounded above by the product `(∑ k ∈ Finset.range N, w k * a.levelNorm k) * (∑ j ∈ Finset.range N, w j * b.levelNorm j)` via `cauchy_range_sum_le` for nonnegative sequences. Bounding each finite partial sum by the corresponding full series `normW w a` and `normW w b` (`Summable.sum_le_tsum` under `ha` and `hb`) gives `∑ n ∈ Finset.range N, w n * (a ⊗ₜ b).levelNorm n ≤ C_w * normW w a * normW w b` for every `N`. Uniform boundedness of nonnegative partial sums implies summability (`summable_of_sum_range_le`), proving `MemTw w (a ⊗ₜ b)`, and passing to the infinite sum via `tsum_le_of_sum_range_le` yields `normW w (a ⊗ₜ b) ≤ C_w * normW w a * normW w b`.
