**Theorem** (`tail_norm2wInv_le_ratio_mul_normW`). Let `w, w' : Weight` be two weights, `b : ExtTensorAlgebra d` satisfy `MemTw w' b`, `N : ℕ` be a cutoff level, and `ρ : ℝ` satisfy `0 ≤ ρ` and `w n / w' n ≤ ρ` for all `n > N`. Then the tail `projGt N b` belongs to `MemL2wInv w (projGt N b)` and satisfies `norm2wInv w (projGt N b) ≤ ρ * normW w' b`.

Proof. For every `n : ℕ`, `w n * (projGt N b).levelNorm n` is nonnegative. Rewriting `(projGt N b).levelNorm n` via `projGt.levelNorm` and splitting on `N < n` shows that `w n * (projGt N b).levelNorm n ≤ ρ * (w' n * b.levelNorm n)` for all `n`: when `N < n`, positivity of `w' n` turns `w n / w' n ≤ ρ` into `w n ≤ ρ * w' n`, which multiplies through by the nonnegative `b.levelNorm n`; when `n ≤ N`, the left-hand side is zero while the right-hand side is nonnegative because `ρ ≥ 0`, `w' n > 0`, and `b.levelNorm n ≥ 0`. Since `MemTw w' b` gives summability of `n ↦ w' n * b.levelNorm n`, scaling by `ρ` produces a summable majorant, whence `MemTw w (projGt N b)` holds by `Summable.of_nonneg_of_le`. Applying `memL2wInv_of_memTw` to `projGt N b` yields both `MemL2wInv w (projGt N b)` and `norm2wInv w (projGt N b) ≤ normW w (projGt N b)`. Finally, comparing `tsum`s termwise via the pointwise bound and factoring `ρ` out with `tsum_mul_left` bounds `normW w (projGt N b)` by `ρ * normW w' b`.
