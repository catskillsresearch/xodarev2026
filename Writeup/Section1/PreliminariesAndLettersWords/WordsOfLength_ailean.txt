**Definition** (`wordsOfLength`). Given an alphabet size $d \in \mathbb{N}$, `wordsOfLength d : ℕ → Finset (Word d)` defines the finite set of words of length $n$ over `Fin d` recursively on $n$: `wordsOfLength d 0` is the singleton `{[]}` containing the empty word, and `wordsOfLength d (n + 1)` is the disjoint union (`Finset.biUnion`) over all letters $i \in \mathrm{Fin}\, d$ (`Finset.univ`) of the image (`Finset.map`) of `wordsOfLength d n` under the injective prepending map $I \mapsto i :: I$ (injectivity given by `(List.cons.inj h).2`).

**Lemma** (`wordsOfLength.mem`). For any $d, n \in \mathbb{N}$ and word $I$ (`I : Word d`), $I \in \mathrm{wordsOfLength}(d, n)$ (`I ∈ wordsOfLength d n`) if and only if $I.\mathrm{length} = n$ (`I.length = n`).

Proof. Proceed by pattern-matching recursion on $n$ and $I$. The cases $(0, [])$, $(0, \_ :: \_)$, and $(n + 1, [])$ follow immediately by unfolding `wordsOfLength` and simplifying. In the inductive case $(n + 1, i :: I)$, unfolding `wordsOfLength` and simplifying membership in `Finset.biUnion`, `Finset.univ`, and `Finset.map` together with `List.length_cons` and `Nat.add_right_cancel_iff` reduces the equivalence to $(\exists a\, J,\, J \in \mathrm{wordsOfLength}(d, n) \wedge a :: J = i :: I) \leftrightarrow I.\mathrm{length} = n$. In the forward direction, list-cons injectivity (`cases hcons`) identifies $a = i$ and $J = I$, and the recursive call `wordsOfLength.mem.mp` gives `I.length = n`; conversely, if `I.length = n`, choosing $a = i$ and $J = I$ with `wordsOfLength.mem.mpr` gives the required witness.

**Lemma** (`wordsOfLength.succ`). For any $d, n \in \mathbb{N}$ and function $F : \mathrm{Word}\, d \to \mathbb{R}$,
$$\sum_{I \in \mathrm{wordsOfLength}(d, n + 1)} F(I) = \sum_{i : \mathrm{Fin}\, d} \sum_{J \in \mathrm{wordsOfLength}(d, n)} F(i :: J).$$

Proof. For each letter $i : \mathrm{Fin}\, d$, let `emb i` be the embedding $I \mapsto i :: I$ and let `t i` be `(wordsOfLength d n).map (emb i)`. The family `t` is pairwise disjoint over `Finset.univ` (`Set.PairwiseDisjoint`): if a word $L$ belongs to both `t i` and `t j` with $i \ne j$, unpacking `Finset.mem_map` expresses $L$ simultaneously as $i :: \_$ and $j :: \_$, contradicting $i \ne j$ by head injectivity `(List.cons.inj hcons).1`. Since `wordsOfLength d (n + 1)` is definitionally `Finset.univ.biUnion t`, `Finset.sum_biUnion` splits the sum over `Fin d` into $\sum_i \sum_{x \in t(i)} F(x)$, and rewriting each inner sum with `Finset.sum_map` yields $\sum_i \sum_{J \in \mathrm{wordsOfLength}(d, n)} F(i :: J)$.

**Lemma** (`wordsOfLength.take_drop_sq`). For any $d, k, n \in \mathbb{N}$ with $k \le n$ and functions $f, g : \mathrm{Word}\, d \to \mathbb{R}$,
$$\sum_{I \in \mathrm{wordsOfLength}(d, n)} \bigl(f(I.\mathrm{take}\, k)\, g(I.\mathrm{drop}\, k)\bigr)^2 = \left(\sum_{J \in \mathrm{wordsOfLength}(d, k)} f(J)^2\right)\left(\sum_{K \in \mathrm{wordsOfLength}(d, n - k)} g(K)^2\right).$$

Proof. Proceed by recursion on $k$ and $n$. When $k = 0$, `wordsOfLength d 0` is `{[]}`, $I.\mathrm{take}\, 0 = []$, and $I.\mathrm{drop}\, 0 = I$, so simplifying with `mul_pow` and `Finset.mul_sum` factors out $f([])^2$. The case $(k + 1, 0)$ is vacuous since $k + 1 \le 0$ contradicts `Nat.not_succ_le_zero k`. In the inductive case $(k + 1, n + 1)$, `Nat.le_of_succ_le_succ` gives $k \le n$; rewriting $(n + 1) - (k + 1) = n - k$ (`Nat.add_sub_add_right`), expanding the outer sums over words of lengths $n + 1$ and $k + 1$ via `wordsOfLength.succ`, and simplifying `(i :: J).take (k + 1) = i :: J.take k` and `(i :: J).drop (k + 1) = J.drop k` (`List.take`, `List.drop`), we apply the recursive hypothesis `wordsOfLength.take_drop_sq` for $(k, n)$ to the shifted function $J \mapsto f(i :: J)$ and $g$ for each $i : \mathrm{Fin}\, d$, and finally factor the common sum over $K$ out of the sum over $i$ via `Finset.sum_mul`.
