**Theorem** (`signature_filtration_eq_brownian_filtration`). For any `setup : ProlongedBrownianSetup Ω ℙ d T` and any time `t : ℝ`, the prolonged-signature σ-algebra coincides with the Brownian σ-algebra: `setup.signatureFiltration.σAlg t = setup.brownianFiltration.σAlg t`.

Proof. Prove equality by double inclusion (`le_antisymm`) on the lattice of `MeasurableSpace`s. For `setup.signatureFiltration.σAlg t ≤ setup.brownianFiltration.σAlg t`, bound the indexed supremum over `s : {s : ℝ // 0 ≤ s ∧ s ≤ t}` and `I : Word (d + 1)` using `iSup_le`: for each `(s, I)`, `setup.sig_adapted_to_W t s I` asserts that `ω ↦ (setup.W_hat s.1 ω).coeff I` is measurable with respect to `setup.brownianFiltration.σAlg t`, so its pullback σ-algebra (`MeasurableSpace.comap`) lies below `setup.brownianFiltration.σAlg t` (`Measurable.comap_le`).

For the reverse inclusion `setup.brownianFiltration.σAlg t ≤ setup.signatureFiltration.σAlg t`, fix `s : {s : ℝ // 0 ≤ s ∧ s ≤ t}` and a Brownian coordinate `i : Fin d`. By the level-1 spatial signature axiom `setup.sig2_space 0 s.1 ω i` combined with `setup.W_zero ω i`, the increment `(setup.W_hat s.1 ω).coeff [i.succ]` equals `setup.W s.1 ω i - 0 = setup.W s.1 ω i` pointwise in `ω`. Rewriting `ω ↦ setup.W s.1 ω i` as the single-letter signature coordinate `ω ↦ (setup.W_hat s.1 ω).coeff [i.succ]` identifies its pullback σ-algebra with the `(s, [i.succ])` summand of `setup.signatureFiltration.σAlg t`, which is bounded above by the supremum via `le_iSup_of_le`.
