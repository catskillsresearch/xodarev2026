**Definition** (`signatureFiltration`). Given `setup : ProlongedBrownianSetup Ω ℙ d T`, `setup.signatureFiltration : IndexedFiltration Ω` is the filtration `generatedFiltration (fun u I ω => (setup.W_hat u ω).coeff I) (setup.sig_meas 0)` generated by all word coordinates `I : Word (d + 1)` of the prolonged signature `setup.W_hat`.

**Lemma** (`priceFiltration_le`). Let `setup : ProlongedBrownianSetup Ω ℙ d T` and let `S : ℝ → Ω → ℝ` be a measurable process (`hS_meas : ∀ t, Measurable (S t)`) adapted to `setup.signatureFiltration` in the sense that `S s.1` is `setup.signatureFiltration.σAlg t`-measurable for every `t : ℝ` and `s : {s : ℝ // 0 ≤ s ∧ s ≤ t}`. Then at every time `t : ℝ`, `(priceFiltration S hS_meas).σAlg t ≤ setup.signatureFiltration.σAlg t`.

Proof. Taking `iSup_le` over `s : {s : ℝ // 0 ≤ s ∧ s ≤ t}` and the trivial `Unit` index in `priceFiltration`, each pullback σ-algebra is bounded by `setup.signatureFiltration.σAlg t` directly from `(hS_adapt t s).comap_le`.
