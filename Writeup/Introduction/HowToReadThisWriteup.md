# How to read this writeup

The report is organised around the Palomar registration: what is proved, what is refuted, and that nothing is open. The official Palomar description and the claim-to-Lean strength table appear first, verbatim. Each later section then expands to group barrels and one leaf per first-party Lean module (212 files). A leaf opens with a short summary of what that module defines or proves. Where the module corresponds to a definition or theorem in the source paper, a green box recaps the paper's mathematical-English statement. The Lean source follows. Headline entry points are the declarations named in the Palomar table; the compared forms are the `…_unwrapped` theorems in `Unwrapped`.
