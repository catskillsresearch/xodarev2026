# Comparator: what is compared and what it means

`comparator.json` lists exactly the results this repository proves, with no `sorry`
(axioms: `propext`, `Quot.sound`, `Classical.choice`). The Challenge
(`SignatureVolatilityComparator/Challenge.lean` and `ChallengeParts/**`) is generated by
`scripts/gen_challenge.sh`. That script copies every declaration the compared statements
depend on verbatim from `SignatureVolatility/`, keeping the module structure, and replaces the
compared proofs with `sorry`. To check it, run
`PALOMAR_QUIET=1 bash scripts/compare_challenge_solution_types.sh`.

| Compared theorem | Paper item | Status (board label) |
|---|---|---|
| `theorem_A` | Theorem A | proved |
| `theorem_B_proved` | Theorem B: martingale on the signature filtration, NFLVR, every coordinate special semimartingale | proved (partial Theorem B, see below) |
| `not_theorem_C`, `theorem_C_refuted`, `blackScholes_isCompleteWithCalls` | Theorem C | refuted: Black–Scholes is complete with calls, but `N^*_S = ∞` (`CounterExample_TheoremC`) |
| `theorem_C_depth_infinite`, `theorem_C_blackScholes_depth_infinite` | Theorem C right-hand side | `N^*_S = ∞` whenever `L²(ℱ^S_T)` is infinite-dimensional, and for Black–Scholes |
| `theorem_D` | Theorem D / Thm 66, GKW projection | proved (`Half_TheoremD`) |
| `theorem_D_residual_hypothesis_fails` | Theorem D, residual expansion "if `N^*_S < ∞`" | hypothesis fails for Black–Scholes (`CounterExample_TheoremD`) |
| `not_prop58_blackScholes_depth_zero`, `blackScholes_completenessDepth_eq_top` | Proposition 58 | refuted: Black–Scholes has `N^*_S = ∞`, not 0 (`CounterExample_Prop58`) |
| `not_lemma77_shuffle_estimate`, `not_lemma77_of_hypH2` | Lemma 77 | refuted for every (H2) weight (`CounterExample_Lemma77`) |
| `not_lemma78_local_lipschitz` | Lemma 78 | refuted: `ℛ` is unbounded on the unit ball of `T_w` for `w ≡ 1` (`CounterExample_Lemma78`) |

The other `theorem_names` entries are supporting facts: Itô/Doléans kit, Brownian driver, and
signature properties. They sit in the dependency closure of the statements above, so the
Solution must prove them too.

**Theorem B is only partly proved.** The full `theorem_B` also asserts the Riccati duality
clause. That clause rests on the open hole `signatureRiccatiKit_of_setup.affine_riccati_duality`,
so `theorem_B` depends on `sorryAx` and is deliberately **not** compared. Only the proved conjuncts
(`theorem_B_proved`) are compared.

**Open problem.** `affine_riccati_duality` (`SignatureRiccatiKit/OfSetup.lean`, paper Thm 4.2(ii),
p. 21; proof §4.4, p. 23) is stated at paper strength and left as the single `sorry` in the
library. The paper's argument for it is unsupported: H3 and polynomial moment bounds do not give
the uniform integrability it claims, and its Lemma 4.10 uses the false Lemmas B.1/B.2 (our
Lemma 77/78 counterexamples). No counterexample has been found, and the closest literature
(Cuchiero–Svaluto-Ferro–Teichmann, arXiv:2302.01362, Thm 3.5) assumes the true-martingale property
that would close it. Because `theorem_B` depends on it, `theorem_B` is not compared.
